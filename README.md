# Nhập môn An toàn thông tin — Source bài lab (ICTU)

Kho lưu source học tập môn Nhập môn ATTT. Mỗi bài một thư mục riêng.

## Cấu trúc
```
Bai1/
  lab1.pdf        # Đề bài thực hành (PDF)
  source/         # Script và source cần thiết cho bài lab
Bai2/
  lab2.pdf
  source/
...
```

> Lưu ý an toàn/pháp lý: mọi thao tác quét, thử nghiệm chỉ thực hiện trong
> máy ảo / mạng nội bộ lab / mục tiêu được cấp phép. Không quét hệ thống
> trên Internet khi chưa được chủ sở hữu cho phép.
